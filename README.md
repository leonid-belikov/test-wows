# Home Task for the World of Warships, PC

This is my implementation of the home task created during the recruitment process for the **Senior Frontend Developer**
position.

## 🕹️ Live demo

You can view the application [here](https://leonid-belikov.github.io/test-wows/).

## ⚙️ How to run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/leonid-belikov/test-wows.git
   cd repo-name
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.
